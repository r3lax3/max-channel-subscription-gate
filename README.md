# max-channel-subscription-gate

Бот для MAX: продаёт подписку на закрытый клуб (групповой чат). Оплата идёт через Prodamus. Оплатившим бот выдаёт ссылку на клуб, неоплативших и тех, у кого подписка истекла, удаляет. Аналог [telegram-channel-subscription-gate](https://github.com/r3lax3/telegram-channel-subscription-gate).

Ограничения MAX и принятые решения описаны в `docs/adr/`, исследование API — в `docs/research/max-bot-api.md`.

## Что умеет

- `/start`: описание клуба, выбор тарифа (месяц, квартал, полгода) и ссылка на оплату Prodamus. Если подписка уже активна, бот показывает срок и ссылку на клуб.
- После оплаты бот сам присылает ссылку на клуб.
- Если человек вошёл в клуб без подписки, бот его удаляет и пишет в личку.
- Раз в час бот напоминает об окончании подписки за 3 дня, удаляет истёкших и сообщает владельцам, если удалить не удалось.
- `/admin` (для `owner_ids`): рассылка (текст или фото), карточка пользователя (продлить до даты, снять подписку, тариф «старичка»), статистика.
- `/id`: показывает ваш MAX ID.

## Запуск

```bash
cp .env.example .env   # заполнить
docker compose up -d --build
```

### Первичная настройка

1. Напишите боту `/id` и впишите свой MAX ID в `owner_ids`. Перезапустите бота.
2. Добавьте бота в группу клуба администратором с правами **«Читать все сообщения»** и **«Удалять участников»**. Бот пришлёт владельцам `chat_id` группы.
3. Впишите `chat_id` в `gated_chat_ids`, ссылку-приглашение в `invite_links`, затем перезапустите бота.
4. Тех, кто уже состоит в группе и должен остаться бесплатно, заведите через `/admin` → «Пользователи» → MAX ID → «Продлить до даты». После этого можно включить `reconcile_members=true`.
5. Prodamus: опубликуйте `/prodamus/webhook` по HTTPS (прокси на порт 8081) и **добавьте этот URL в кабинете Prodamus**: «Настройки → URL для уведомлений» (кнопка «+», адрес TG-бота оставьте). Проверьте тестовым уведомлением (кнопка 🔁). Тот же URL впишите в `prodamus_notification_url`.

### Webhook MAX (рекомендуется для production)

По умолчанию события приходят через long polling. MAX рекомендует webhook: задайте `max_webhook_url=https://<домен>/maxgate/max/webhook` (HTTPS, порт 443) и `max_webhook_secret`. Бот сам оформит подписку и будет её поддерживать.
