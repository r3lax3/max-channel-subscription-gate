# max-channel-subscription-gate

Бот для MAX продаёт подписку на закрытый клуб (групповой чат). Оплата идёт через Prodamus. Оплатившим бот выдаёт ссылку на клуб, неоплативших и тех, у кого подписка истекла, удаляет. Это аналог [telegram-channel-subscription-gate](https://github.com/r3lax3/telegram-channel-subscription-gate).

Решения и ограничения MAX описаны в `docs/adr/`, исследование API — в `docs/research/max-bot-api.md`, термины — в `GLOSSARY.md`.

> **Закрыть можно только группу, не канал.** В MAX бот не может удалять подписчиков канала, поэтому клубом должен быть групповой чат. Канал можно вести рядом как публичную витрину (ADR 0001).

## Что умеет

- `/start`: описание клуба, выбор тарифа (месяц, квартал −10%, полгода −15%), ссылка на оплату Prodamus. Если подписка уже активна, бот показывает срок и ссылку на клуб.
- После оплаты бот сам присылает ссылку на клуб.
- Если человек вошёл в клуб без подписки, бот удаляет его и пишет об этом в личку.
- Раз в час бот:
  - напоминает об окончании подписки за 3 дня;
  - удаляет тех, у кого подписка истекла;
  - по желанию сверяет состав группы с базой.
- `/admin` (для `owner_ids`):
  - рассылка (текст или фото);
  - карточка пользователя: продлить до даты, бесплатный доступ, тариф «старичка», снять подписку;
  - статистика.
- `/id`: показывает ваш MAX ID.
- О проблемах бот пишет владельцам:
  - нет прав в группе;
  - не удалось удалить участника;
  - бота убрали из группы;
  - пришла оплата, которую не удалось привязать к подписке.

## Установка

### 1. Бот и токен

Бота создают в [кабинете MAX для бизнеса](https://business.max.ru) (нужен аккаунт организации): «Чат-боты» → создать бота. Токен находится в разделе интеграции бота, его нужно вписать в `bot_token`.

### 2. Тексты клуба

`gatebot/texts.py` содержит тексты конкретного клуба: имя автора, ссылки, описание. Перед запуском их нужно отредактировать. Цены задаются в `.env`.

### 3. Сервер

Нужен сервер с docker и доменом с HTTPS. Prodamus и MAX шлют уведомления только на HTTPS, MAX — только на порт 443.

```bash
git clone https://github.com/r3lax3/max-channel-subscription-gate && cd max-channel-subscription-gate
cp .env.example .env   # заполнить
docker compose up -d --build
docker compose logs -f bot
```

Бот слушает `127.0.0.1:8081`. Пример nginx, при котором приложение доступно по `https://<домен>/maxgate/`:

```nginx
location /maxgate/ {
    proxy_pass http://127.0.0.1:8081/;   # слэш в конце убирает префикс /maxgate
}
```

Сертификат можно получить через certbot: `certbot --nginx -d <домен>`. Проверка: `curl https://<домен>/maxgate/health` должен вернуть `OK`.

### 4. Первичная настройка

1. Напишите боту `/id`, впишите свой MAX ID в `owner_ids` и выполните `docker compose up -d`.
2. Добавьте бота в группу клуба. Затем в клиенте MAX: настройки группы → «Администраторы» → бот, с правами **«Читать все сообщения»** и **«Удалять участников»**. Бот пришлёт владельцам `chat_id` группы.
3. Впишите `chat_id` в `gated_chat_ids`. В `invite_links` впишите ссылку-приглашение группы (настройки группы → «Ссылка-приглашение»). Если `invite_links` пуст, бот попробует взять ссылку из настроек чата. Выполните `docker compose up -d`. При старте бот проверит группу и права и напишет владельцам, если что-то не так.
4. Тех, кто уже состоит в группе и должен остаться бесплатно, заведите через `/admin` → «Пользователи» → MAX ID → «Выдать бесплатный доступ». Если владелец сам добавит человека в группу, бот его не удалит, но спросит владельцев, выдать ли бесплатный доступ. После этого можно включить `reconcile_members=true`.
6. Проверьте вход по ссылке со второго аккаунта без подписки: бот должен удалить его и написать в личку.
5. Prodamus:
   - добавьте `https://<домен>/maxgate/prodamus/webhook` в кабинете: «Настройки → URL для уведомлений»;
   - если кабинет общий с другим ботом, его адрес не удаляйте: боты отсеивают чужие уведомления (ADR 0003);
   - проверьте тестовым уведомлением (кнопка 🔁);
   - тот же адрес впишите в `prodamus_notification_url`.

### 5. Webhook MAX (рекомендуется)

По умолчанию события приходят через long polling. MAX советует webhook:

```
max_webhook_url=https://<домен>/maxgate/max/webhook
max_webhook_secret=<5–256 символов A-Za-z0-9_->
```

Бот сам оформит подписку и будет её поддерживать.

## Эксплуатация

- Логи: `docker compose logs -f bot`.
- Обновление: `git pull && docker compose up -d --build`. Миграции БД применяются автоматически при старте.
- После правки `.env` нужен `docker compose up -d`.
- Бэкап: `docker compose exec postgres pg_dump -U maxgate maxgate > backup.sql`.
