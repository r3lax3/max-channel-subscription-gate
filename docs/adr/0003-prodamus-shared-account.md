# 0003. Изоляция от TG-бота на общем аккаунте Prodamus

Статус: принято, 2026-10-16

## Контекст

TG-бот и MAX-бот могут работать на одном аккаунте Prodamus. URL вебхука в кабинете один. TG-бот при неизвестном `order_id` ищет пользователя по `customer_extra` как по telegram_id, а MAX ID может совпасть с чьим-то Telegram ID.

## Решение

- В каждой платёжной ссылке передаём `urlNotification` (`prodamus_notification_url`), чтобы вебхук о MAX-оплате приходил этому боту.
- `customer_extra` имеет вид `max:<id>`. TG-бот такой платёж игнорирует, наш бот игнорирует голые числа.
- Вебхук проверяет подпись Prodamus (заголовок `Sign`). Без неё «оплатить» подписку мог бы кто угодно, знающий URL.
