# Глоссарий

- **Клуб** — закрытый групповой чат в MAX, доступ в который продаётся по подписке.
- **Закрытый чат (gated chat)** — групповой чат из `gated_chat_ids`, куда бот пускает только подписчиков. Каналы такими быть не могут (ADR 0001).
- **Подписка** — оплаченный период доступа: `User.subscription_end_date` и `is_active`.
- **Тариф** — срок оплаты: месяц, квартал (−10%) или полгода (−15%). Цена считается от месячной.
- **Старичок (legacy pricing)** — пользователь, сохраняющий льготную месячную цену, пока подписка непрерывна. Флаг ставится при оплате во время акции или из админки, при разрыве подписки снимается.
- **Акция** — период до `legacy_promo_until`, когда все платят льготную цену и становятся старичками.
- **Владелец (owner)** — MAX ID из `owner_ids`: доступ к `/admin`, право находиться в клубе без подписки, получает уведомления бота.
- **Кик** — удаление участника из закрытых чатов (`block=false`, чтобы человек мог вернуться после оплаты).
- **Посторонний (stranger)** — участник закрытого чата без активной подписки. Удаляется при входе или сверкой.
- **MAX ID** — `user_id` пользователя в MAX (int64). С Telegram ID не совпадает.
